# SEMATARY_BOT
# Telegram-бот для автоматического наложения текста на изображения

Репозиторий содержит исходный код Telegram-бота, написанного на языке Python. Проект предназначен для автоматизации процесса нанесения текстовых надписей на графические файлы (изображения) с динамическим управлением геометрией текста.

Проект выполнен в рамках учебной дисциплины «Программирование».

## Основной функционал

* **Два режима обработки входящих запросов:**
  * Прием изображения со встроенной подписью (капшеном) — мгновенная генерация и отправка итогового файла.
  * Раздельный прием данных — последовательное сохранение состояния сессии (сначала графический файл, затем текстовое сообщение).
* **Алгоритм адаптивного форматирования (библиотека Pillow):**
  * Посимвольный перенос длинных лексем (защита от монолитных строк без пробелов, нарушающих границы кадра).
  * Динамический рекурсивный подбор кегля (размера) шрифта на основе анализа метрик текстового блока через `draw.textbbox`.
  * Автоматический расчет межстрочных интервалов и центрирование текста по горизонтали.
* **Обеспечение читаемости:** Нанесение текста белым цветом со строго пропорциональной контрастной черной обводкой (`stroke_width`), обеспечивающей разборчивость символов на любом цветовом фоне.
* **Безопасность и оптимизация ресурсов:** Авторизационный токен считывается из переменных окружения (скрыт из исходного кода). Обработка медиафайлов происходит исключительно в оперативной памяти сервера с использованием буфера `io.BytesIO` без сохранения на локальный диск.

## Стек технологий

* **Язык программирования:** Python 3.10+
* **Взаимодействие с API Telegram:** `python-telegram-bot` (v20.x+)
* **Обработка графики и шрифтов:** `Pillow` (PIL)

## Инструкция по развертыванию и запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com
cd SEMATARI-BOT-
```

### 2. Установка зависимостей
Для корректной работы приложения установите необходимые пакеты с помощью менеджера `pip`:
```bash
pip install python-telegram-bot pillow
```

### 3. Локальное размещение шрифтов
Для корректной отрисовки кириллического алфавита поместите используемый TrueType-шрифт (например, `Arial Bold`) в корневую директорию проекта под именем `font.ttf` либо убедитесь в наличии стандартных системных шрифтов по путям, указанным в коде.

### 4. Инициализация и запуск

Перед запуском необходимо передать полученный от @BotFather токен в переменную окружения `BOT_TOKEN`.

* **Для операционных систем Linux / macOS:**
  ```bash
  export BOT_TOKEN="ВАШ_ТОКЕН_БОТА"
  python main.py
  ```

* **Для операционной системы Windows (PowerShell):**
  ```powershell
  $env:BOT_TOKEN="ВАШ_ТОКЕН_БОТА"
  python main.py
  ```

## Архитектура приложения и ключевые компоненты

* `load_font(size)` — функция безопасной загрузки (.ttf) шрифта с поддержкой кириллицы из локальной директории или системных путей ОС.
* `wrap_text(...)` — метод разбиения входящей строки на блоки с учетом ограничения максимальной ширины (до `90%` от ширины исходного изображения).
* `add_text(...)` — центральный компонент обработки графики, реализующий наложение текста, расчет параметров обводки и конвертацию структуры в байтовый поток JPEG.
* `on_photo(...)` / `on_text(...)` — асинхронные обработчики входящих апдейтов от платформы Telegram.
